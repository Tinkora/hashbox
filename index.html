核心功能

为开发者打造的隐私优先哈希工具箱

多算法支持

SHA-256、SHA-384、SHA-512、MD5、BLAKE3 — 五种算法，统一 API。

实时计算

文本输入即算，80ms 防抖。文件拖放即可获取哈希值。

HMAC 认证

支持 HMAC-SHA-256 和 HMAC-SHA-512，消息认证码一键生成。

隐私优先

所有计算在浏览器 WASM 中完成，数据绝不上传服务器。

高性能

Rust 编译到 WASM，接近原生速度。BLAKE3 支持并行哈希。

文件哈希

拖放任意文件，FileReader API + WASM 本地计算，支持大文件。

安装与运行

需要 Rust 工具链和 wasm-pack。一行命令启动本地哈希工具箱。

1. 克隆并构建

# 克隆仓库
git clone https://github.com/Tinkora/hashbox.git
cd hashbox

# 构建 Web WASM
wasm-pack build --target web crates/hashbox_web

2. 启动本地服务器

cp crates/hashbox_web/pkg/* crates/hashbox_web/static/pkg/
cd crates/hashbox_web/static
python3 -m http.server 8080

# 浏览器打开 http://localhost:8080

使用流程

三步完成哈希计算

1

选择算法

点击 SHA-256、BLAKE3 或 MD5 等算法标签，一键切换。

2

输入内容

在文本框输入文字（实时计算），或拖放文件到拖放区。

3

复制结果

点击复制按钮，哈希值即复制到剪贴板。
