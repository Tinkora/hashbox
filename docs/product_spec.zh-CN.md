# hashbox 产品规格

## 产品一句话

浏览器原生的多算法哈希工具箱。支持文本和文件哈希，所有计算在 WASM 中完成，数据绝不上传。

## 目标用户

- 需要快速计算文件校验和的开发者
- 需要验证下载文件完整性的用户
- 需要 HMAC 消息认证的后端/安全工程师
- 关注隐私、不希望数据离开本地的用户

## 核心体验

1. 用户打开网页，无需安装任何软件
2. 选择所需算法（SHA-256 默认）
3. 在文本框输入文字——实时显示哈希值
4. 或拖放文件到拖放区——自动计算文件哈希
5. 可选使用 HMAC 功能，输入密钥和消息
6. 点击复制按钮，哈希值复制到剪贴板
7. 全程数据在浏览器 WASM 中处理，零网络请求

## 支持的算法

| 算法 | 摘要长度 | 用途 |
|------|---------|------|
| SHA-256 | 32 字节 | 通用完整性校验（默认） |
| SHA-384 | 48 字节 | 抗长度扩展攻击 |
| SHA-512 | 64 字节 | 64 位平台高性能 |
| MD5 | 16 字节 | 仅用于传统校验和——无碰撞抗性 |
| BLAKE3 | 32 字节 | 极速并行哈希 |

## HMAC 支持

- HMAC-SHA-256
- HMAC-SHA-512
- 密钥不能为空

## 技术架构

```
浏览器 (HTML/JS)
  ↕ wasm-bindgen
WASM (hashbox_core → hashbox_web)
  ├── sha2 0.10 (SHA-256/384/512)
  ├── md-5 0.10 (MD5)
  ├── blake3 1.5 (BLAKE3)
  ├── hmac 0.12 (HMAC)
  └── hex 0.4 (编码)
```

所有哈希计算在 WASM 中执行。JS 层仅负责：
- 算法选择和 UI 交互
- FileReader API 读取文件字节
- 将 `Uint8Array` 传递给 WASM
- 显示结果和复制到剪贴板

## 隐私模型

- **零上传**: 文本、文件、密钥均不离开浏览器
- **零遥测**: 无分析、无追踪、无错误上报
- **纯静态**: HTML + JS + WASM，可离线使用

## MVP 范围

- 五种哈希算法（SHA-256/384/512、MD5、BLAKE3）
- 实时文本哈希（80ms 防抖）
- 文件拖放哈希
- HMAC-SHA-256 和 HMAC-SHA-512
- 一键复制结果
- 中文 UI
- 所有计算在 WASM 中

## 非目标

- 不做文件上传 / 云哈希
- 不做哈希比对数据库（如 VirusTotal）
- 不做用户账户系统
- 不做历史记录存储
- 首版不做流式大文件分片哈希（可通过 HashWriter API 扩展）
